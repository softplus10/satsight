# Internationalization

English is the default and the only bundled language. Device language does not change it automatically. There is no language selector while only one language is available.

## Messages

`src/lib/i18n/en.ts` defines the source catalog and the `MessageKey` type. Use the shared helper in components and application errors:

```ts
import { t } from '$lib/i18n';

t('add_wallet');
t('remove_wallet_confirm', { name: wallet.name });
t('wallet_count', { count: 1 }); // "1 wallet"
t('wallet_count', { count: 2 }); // "2 wallets"
```

Keys and required interpolation parameters are checked by TypeScript. Keep complete sentences and count phrases in the catalog rather than joining translated fragments. Render translations through normal Svelte text expressions; do not use `{@html}`.

Plural messages use `Intl.PluralRules`. Each must provide `other`; add `zero`, `one`, `two`, `few`, or `many` where the language requires them. Interpolation values are rendered as plain text. Format numeric values with `formatNumber` before interpolation when grouping or decimal formatting is needed.

Protocol identifiers, network values in stored records, addresses, BTC/sats units, currency codes, and the SatSight name are not translated.

## Add a language

1. Create a catalog such as `src/lib/i18n/fr.ts` with the same keys and placeholders as English. Use `satisfies TranslationCatalog` to reject unknown keys. Partial catalogs are allowed and fall back to English.
2. Import and register it in `src/lib/i18n/catalogs.ts` using a BCP 47 language tag such as `fr` or `pt-BR`.
3. Call `setLocale('fr')` from the future language preference control. The runtime resolves an exact registered locale, then a registered base language, then English. Persist that preference when adding the control.
4. Run `npm run check` and `npm test`. Catalog tests verify that translations preserve interpolation parameters.

```ts
import type { TranslationCatalog } from './translate';

export const fr = {
	add_wallet: 'Ajouter un portefeuille',
	wallet_count: {
		one: '{count} portefeuille',
		other: '{count} portefeuilles'
	}
} satisfies TranslationCatalog;
```

`t()`, `formatNumber()`, and `formatDate()` read Svelte locale state, so expressions update when `setLocale()` is called. Use `$derived` for translated arrays or computed labels in components; avoid translating once at module initialization. The root layout updates the document's `lang` attribute.

## Stored data and native metadata

Generated address labels are translated at render time. New records store an empty default label. `addressLabel()` also recognizes older generated English/Korean labels without rewriting records. Custom labels, wallet names, and transaction notes remain user data and are never translated.

Application errors and in-progress operations use the language active when they occur. Previously saved error messages are not rewritten by a locale change.

Static HTML, the web manifest, and iOS camera permission text use English fallback copy. Additional native permission translations need the platform's localized resource files; adding a web catalog alone does not localize operating-system dialogs.
